Starting the server

From the folder you loaded this extension out of:

pip install -r server/requirements.txt
python server/server.py

Add --cookies-from-browser chrome to reach videos that need you to be logged in, or --dir <path> to change where files land. ffmpeg must be on your PATH for merged MP4 and MP3 output.
